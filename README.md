# Eagle 同步器 (Eagle-Syncer)

基于局域网的 [Eagle](https://eagle.cool) 素材库同步插件。通过 mDNS 自动发现同一局域网内的设备，支持主机/客户端双模式，将 Eagle 文件夹及素材增量同步到其他设备。

---

## 功能特性

- **自动发现**：使用 Bonjour/mDNS 自动发现局域网内运行插件的其他设备，无需手动输入 IP（也支持手动输入）
- **主机模式**：将本机 Eagle 库中的文件夹提供给其他设备拉取
- **客户端模式**：从主机拉取指定文件夹，同步到本地 Eagle 库的指定位置
- **增量同步**：基于 MD5 校验，跳过未变更文件，只传输差异内容
- **文件夹树**：可视化浏览 Eagle 文件夹结构，支持搜索、全选、折叠

---

## 环境要求

| 环境 | 要求 |
|------|------|
| [Eagle](https://eagle.cool) | v4.0 及以上（支持插件系统） |
| 操作系统 | macOS / Windows（Eagle 支持的平台） |
| Node.js | Eagle 内置，无需单独安装 |
| 网络 | 同步双方需在同一局域网内 |

## 安装方法

### 方法一：直接加载（推荐开发/测试）

1. 下载或克隆本仓库到本地：
   ```bash
   git clone https://github.com/yuniancong/Eagle-Syncer.git
   ```

2. 打开 Eagle，进入 **插件** → **开发者** → **加载插件**

3. 选择克隆下来的文件夹（包含 `manifest.json` 的目录）

4. 插件加载成功后会出现在插件列表中

### 方法二：安装依赖后使用

进入插件目录，安装 Node.js 依赖（如 Eagle 无法自动加载依赖）：

```bash
cd Eagle-Syncer
npm install
```

> **注意**：Eagle 插件运行在内置的 Node.js 环境中，通常无需手动 `npm install`。如遇 `Cannot find module` 错误，再执行此步骤。

## 使用方法

### 启动插件

在 Eagle 中点击顶部菜单栏 **插件** → **Eagle 同步器** 打开插件窗口。

---

### 主机模式（提供文件）

1. 点击 **主机模式** 按钮
2. 插件自动启动 HTTP 服务（默认端口 `12480`）并广播 mDNS 服务
3. 等待客户端连接，无需其他操作

---

### 客户端模式（接收文件）

1. 点击 **客户端模式** 按钮
2. 插件自动扫描局域网，发现的主机会显示在设备列表中
   - 也可手动在输入框中输入主机的 `IP:端口`（例如 `192.168.1.100:12480`），点击 **连接**
3. 连接成功后，左侧显示主机上的文件夹树
4. 勾选需要同步的文件夹
5. 在顶部下拉菜单选择**同步目标位置**（Eagle 库根目录或指定子文件夹）
6. 点击 **开始同步**，进度条和日志面板会实时显示同步状态

---

### 同步逻辑说明

- 客户端向主机发起请求，拉取选中文件夹内的所有素材
- 文件传输前进行 MD5 校验，本地已有且内容一致的文件**不会重复传输**
- 同步过程中可查看底部日志面板了解详情

## 常见问题

**Q：发现不了局域网设备？**
A：确保两台设备在同一网段，且防火墙未屏蔽 UDP 5353（mDNS）和 TCP 12480 端口。可改用手动输入 IP 连接。

**Q：同步速度慢？**
A：速度取决于局域网带宽和文件大小。增量同步会跳过未变更文件，第二次同步通常更快。

**Q：插件加载后提示找不到模块？**
A：在插件目录执行 `npm install` 安装依赖后重新加载插件。
